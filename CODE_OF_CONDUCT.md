# Code of Conduct

Wellsprings is built with good intention, and that includes how we treat each other.

- Be kind. Critique the code or the sound, not the person.
- Beginners are welcome. Nobody needs to know music theory or Rust to ask a question.
- No harassment, hate or slurs, in issues, PRs or anywhere the project lives.
- Keep the jokes playful. Murmur roasts people for undoing his ideas; we don't roast each other.

Maintainers may remove comments, close issues or block accounts that break these rules.
To report a problem privately, open a GitHub issue asking a maintainer to contact you,
without including the details in public.

This is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
